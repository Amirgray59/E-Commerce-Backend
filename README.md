# E-Commerce Backend with Node.js, TypeScript & Fastify

A backend server for an e-commerce platform built with **Node.js**, **TypeScript**, **Fastify**, **TypeORM**, and **MySQL**.
## Features

- **User Management**: User registration, login, and profile management.
- **Product Catalog**: CRUD for products.
- **Order Processing**: Create and manage customer orders.
- **Database Entities**: Entities using TypeORM.
- **API Endpoints**: RESTful API endpoints with Fastify.

## Tech Stack

- **Runtime**: Node.js
- **Language**: TypeScript
- **Framework**: Fastify
- **ORM**: TypeORM
- **Database**: MySQL


# Install dependencies
```sh
$ npm install
```
